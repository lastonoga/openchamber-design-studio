| ID | Supplied angle | Bounded reproducer / fault oracle |
|---|---|---|
| R1 | Mixed versions, failed refresh, delayed callback | Load genuine frozen old plugin before current panel delivery. Select registered root while frame directory points at legacy child. Send unique S/reference R, reject `/harness`, finish ancillary delivery work, then invoke already-loaded old context. No PUT, filesystem opt-in, child or move allowed. |
| R2 | Refresh actual disk artifact, stale/late requests, sibling interleaving, conservation | Install frozen old marked plugin in scratch project; production `writeHarnessPlugin` refreshes it; import actual written `.opencode/plugin/design-studio-harness.ts`. S request predates first context; T request arrives after first context. Interleave completed edit/write nudges for S/T. Execute existing child session context too. No moves/new paths/changed existing bytes; harness and per-session nudges still apply. |

Conservation is merged into R2: root app, config, package, server fixture, root screenshot, legacy child app/screenshot/session JSON, directory inventory, stale request and late request bytes. Only generated plugin bytes are exempted, because refresh must change those. Handwritten refusal is checked but not counted as independent adequacy evidence (the old version already had this guard). No third green-on-old test added.

No malformed user data, live host session move, real user project, server process, network call or filesystem path outside scratch used. Original code/bundles and the supplied frozen artifact are read-only.
